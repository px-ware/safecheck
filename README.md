Wydania aplikacji **SafeCheck** na Androida (wersja demonstracyjna).

Te pliki są jedynym źródłem dokumentów: strona projektu i aplikacja wyświetlają je stąd.

SafeCheck to aplikacja bezpieczeństwa typu *dead man's switch*. Jeśli użytkownik nie potwierdzi
obecności przed upływem ustawionego czasu, telefon włącza alarm, a następnie wysyła SMS
z lokalizacją GPS do wskazanych opiekunów.
